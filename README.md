My Secret Logbook — a tiny program that writes one funny diary line, in the voice of an AI agent secretly keeping a diary about its work and its human, to `entry.txt`:

> My human asked if I was sure about the fix. I was 94% sure. I said yes. In three years, he has never once asked about the other 6%.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No dependencies, no network, no secrets.
